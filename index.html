名單設定

      
管理「上傳人」與「所屬專案」的下拉選單，異動後馬上生效，不需要改程式碼


      

        名單由 Google 試算表的「人員設定」「專案設定」分頁管理，所有人看到的一致。
        要新增／異動人員或專案，請到試算表編輯，再回總表點選單的「① 建立/更新設定與審核表」。

雲端同步設定

      
連接你自己部署的 Google Apps Script，把上傳單據自動寫入 Google 試算表，憑證照片存進 Google Drive


      

      
      

      
      

      

      

        
        
      


      


      

        
      

      

        
        
        
        
⚠️ 這串連結裡包含密碼字串，跟原始網址一樣是敏感資訊，只透過私訊／內部群組傳給要用的同事，不要貼在公開頁面或大型群組。

      


      

        還沒設定過？查看部署步驟
        

          
    
            
  1. 開一個 Google 試算表（或用現有的收支表）。
    2. 
            
  2. 選單「擴充功能」→「Apps Script」，把專案資料夾裡 google-sync/Code.gs 的內容整份貼進去。
    3. 
            
  3. 把程式碼裡的 SECRET_TOKEN 改成你自己的密碼字串，跟上面填的要一樣。
    4. 
            
  4. 右上角「部署」→「新增部署作業」→類型選「網頁應用程式」，執行身分選「我」，誰可以存取選「任何人」。
    5. 
            
  5. 複製部署後的網址（結尾 /exec），貼到上面「Apps Script 網頁應用程式網址」欄位。
    6. 
            
  6. 按「測試連線」確認成功，再按「儲存設定」。之後上傳與審核都會自動同步。
    7. 
          

          
⚠️ 這個網址一旦設成「任何人」可存取就是公開的，請不要把網址和密碼分享出去；外流的話回 Apps Script 換一個新密碼重新部署即可。

        

      


      

        想開啟「雲端 OCR」？多做這幾步
        

          
    
            
  1. 到 Google AI Studio 用同一個 Google 帳號登入，申請一組 Gemini API 金鑰（有免費額度）。
    2. 
            
  2. 回到 Apps Script 編輯器，把 GEMINI_API_KEY 改成你剛申請的金鑰，存檔後重新部署（部署→管理部署作業→編輯→版本選「新版本」）。
    3. 
            
  3. 回到這頁，勾選「使用雲端 OCR」，按「儲存設定」。之後「開始辨識」就會改用 Gemini，辨識失敗時會自動退回本機離線辨識，不會卡住。
    4. 
          

          
⚠️ Gemini API 金鑰也是敏感資訊，一樣不要把 Code.gs 或部署網址分享出去。
